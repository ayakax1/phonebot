# Бот-фарм телефонов

## Установка
1. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
2. В `config.py`:
   - вставить `BOT_TOKEN` (получить у @BotFather)
   - вставить свой Telegram `user_id` в `ADMIN_IDS` (узнать через @userinfobot)
3. Для работы в группах — у @BotFather выполнить `/setprivacy` → выбрать бота → **Disable**.
   Без этого бот не увидит сообщение "тел" в группе, если оно не адресовано ему напрямую.
4. Запуск:
   ```
   python bot.py
   ```

## Добавление телефона
Отправить боту **фото** с подписью:
```
/addphone Xiaomi Redmi 6A;Мусор;3000
```
Формат: `Модель;Редкость;Базовая_цена`. Фото сохранится в папку `photos/`, путь запишется в базу `phones.db`.

Доступные редкости (можно добавлять/менять в `config.py` → `RARITY_WEIGHTS`):
Мусор, Необычный, Редкий, Эпический, Легендарный, Мифический, Хроматический, Коллекционный, Секретный, Космический.

## Как это работает
- Пользователь пишет **строго** "тел" (без других слов) в личку боту или в группу, **не в ответ** на сообщение → бот выдаёт случайный телефон.
- Редкость выбирается по весам из `RARITY_WEIGHTS` (только среди тех редкостей, где уже есть добавленные модели).
- Статус: 85% "Б/У" (цена ниже базовой на 15–50%), 15% "Новый" (цена выше базовой на 15–50%).
- Перезарядка — 3 часа на пользователя (меняется в `config.py` → `COOLDOWN_SECONDS`).

## Деплой на Render (бесплатно, 24/7)

Render бесплатно даёт только тип **Web Service** (не Background Worker), поэтому
бот запущен вместе с крошечным веб-сервером-заглушкой — это позволяет
задеплоить его как обычный сайт.

**Шаги:**
1. Залейте папку с ботом в репозиторий на GitHub (публичный или приватный —
   не важно).
2. На render.com → **New** → **Web Service** → подключите репозиторий.
3. Настройки сервиса:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Instance Type:** Free
4. В разделе **Environment** добавьте переменную `BOT_TOKEN` со значением
   вашего токена от @BotFather (не пишите токен в коде на GitHub!).
5. Задеплойте. После первого старта Render даст вам публичный URL вида
   `https://ваш-бот.onrender.com`.
6. Чтобы бот не засыпал (у бесплатных Web Service сон через 15 минут без
   запросов) — зарегистрируйтесь на **UptimeRobot** (бесплатно) и добавьте
   монитор типа HTTP(s), который пингует ваш URL каждые 5 минут.

**Ограничения бесплатного тарифа, которые нужно держать в голове:**
- Диск не гарантированно сохраняется между перезапусками контейнера — при
  пересборке (например, после git push) `phones.db` и папка `photos/`
  могут очиститься, и телефоны придётся добавлять заново через `/addphone`.
- Это нормально для тестового этапа — при переезде на Oracle Cloud (или
  другой VPS с постоянным диском) это перестанет быть проблемой.
