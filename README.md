# Бот-фарм телефонов

## Что изменилось
- Фото телефонов больше **не хранятся на диске бота** — сохраняется только
  `file_id` (ссылка на файл, который лежит на серверах Telegram навсегда).
- База данных переехала с локального SQLite на **внешний Postgres (Neon)** —
  живёт отдельно от Render и не зависит от передеплоев/сна сервиса.

Благодаря этому весь каталог телефонов, прогресс игроков и фото переживают
любую пересборку и "засыпание" бесплатного тарифа Render.

---

## Шаг 1. Создать бесплатную базу данных на Neon

1. Зайдите на **neon.tech**, зарегистрируйтесь (можно через GitHub).
2. Нажмите **Create a project**, дайте любое имя, выберите ближайший регион.
3. После создания откроется страница проекта — найдите **Connection string**
   (строка вида `postgresql://user:password@ep-xxx.neon.tech/neondb?sslmode=require`).
4. Скопируйте её целиком — это и есть `DATABASE_URL`, он понадобится в шаге 3.

Таблицы в базе создавать не нужно — бот создаст их сам при первом запуске.

---

## Шаг 2. Настроить бота локально (config.py)

В `config.py` ничего вручную менять не нужно — все секреты (`BOT_TOKEN`,
`DATABASE_URL`) бот берёт из переменных окружения. Единственное, что стоит
проверить — ваш `ADMIN_IDS` (свой Telegram user_id, узнать через
@userinfobot), чтобы `/addphone` работал только у вас.

Если хотите проверить бота локально перед деплоем — можно временно задать
переменные окружения в терминале:
```
set BOT_TOKEN=ваштокен        (Windows)
set DATABASE_URL=строка_из_neon
python bot.py
```

---

## Шаг 3. Деплой на Render

Раз репозиторий на GitHub уже готов — залейте туда обновлённые файлы
(`bot.py`, `database.py`, `config.py`, `requirements.txt`), затем:

1. На render.com → **New** → **Web Service** → выберите свой репозиторий.
2. Настройки сервиса:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Instance Type:** Free
3. Откройте вкладку **Environment** и добавьте две переменные:
   - `BOT_TOKEN` = токен от @BotFather
   - `DATABASE_URL` = строка подключения из Neon (шаг 1)
4. Нажмите **Deploy**. Дождитесь, пока сборка завершится и появится
   публичный URL вида `https://ваш-бот.onrender.com`.

---

## Шаг 4. Не дать боту засыпать

Бесплатный Web Service на Render засыпает после 15 минут без запросов.
1. Зарегистрируйтесь на **uptimerobot.com** (бесплатно).
2. Создайте монитор типа **HTTP(s)**, вставьте туда URL вашего бота с Render.
3. Интервал проверки — 5 минут.

Теперь Render будет получать пинг каждые 5 минут и не станет усыплять сервис.

## Как добавить телефон

Отправьте боту в личку **фото** с подписью:
```
/addphone Xiaomi Redmi 6A;Мусор;3000
```
Формат: `Модель;Редкость;Базовая_цена`. Бот сохранит только `file_id` фото —
само фото остаётся на серверах Telegram. **Не удаляйте это сообщение** у
бота в личке — на нём "держится" file_id.

Доступные редкости (можно менять в `config.py` → `RARITY_WEIGHTS`):
Мусор, Необычный, Редкий, Эпический, Легендарный, Мифический, Хроматический,
Коллекционный, Секретный, Космический.

---

## Как это работает
- Пользователь пишет **строго** "тел" (без других слов), не в ответ на
  сообщение, в личке или в группе → бот выдаёт случайный телефон.
- Редкость выбирается по весам из `RARITY_WEIGHTS` (только среди тех
  редкостей, где уже есть добавленные модели).
- Статус: 85% "Б/У" (цена ниже базовой на 15–50%), 15% "Новый" (цена выше
  базовой на 15–50%).
- Перезарядка — 3 часа на пользователя (`config.py` → `COOLDOWN_SECONDS`).
- Если у телефона нет фото — бот всё равно выдаст его, но допишет внизу:
  "Фото телефона не было найдено."
